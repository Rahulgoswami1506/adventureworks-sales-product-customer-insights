# AdventureWorks Sales, Product & Customer Insights Dashboard

An interactive Power BI dashboard built using the AdventureWorks dataset to analyze sales, product performance, customer behavior, and regional performance.

## Project Overview

This report is designed as a multi-page business intelligence solution with interactive navigation and DAX-driven analysis.

### Report Pages

- Executive Dashboard
- Map Analysis
- Product Detail
- Customer Detail
- Q&A
- Decomposition Tree
- Key Influencers

## Key Capabilities

- Executive KPI reporting
- Sales performance analysis
- Product performance analysis
- Customer analysis
- Regional and geographic analysis
- Interactive slicers and navigation
- Drill-down and exploratory analysis
- DAX-based measures and KPIs

## Skills Used
